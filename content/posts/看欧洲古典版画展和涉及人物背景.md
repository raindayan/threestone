不同绘画类别介绍

| 速写  | 大部分的速写都是快速的[素描](https://zh.wikipedia.org/wiki/%E7%B4%A0%E6%8F%8F "素描")，仅勾勒出一个物体大致轮廓、形体，而不加绘肌理，光影的细节与变化                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 素描  | 素描是在画完雏型的基本功外，再添加细部光影变化的描绘以表现的技巧而言，素描有别于[水彩](https://zh.wikipedia.org/wiki/%E6%B0%B4%E5%BD%A9 "水彩")、[油画](https://zh.wikipedia.org/wiki/%E6%B2%B9%E7%95%AB "油画")，而是重于线条表现方式，以线条的粗细轻重来描述物体的明暗深浅，并且不须顾虑物体细节的色调色值，画面借由明暗光影的衬托来突显主题，但是也由于失去了[彩度](https://zh.wikipedia.org/wiki/%E8%89%B2%E5%BA%A6_\(%E8%89%B2%E5%BD%A9%E5%AD%A6\) "色度 (色彩学)")的考量，素描在明暗的阶调上，分层得很详细，在不同的微细的明暗变化中，都能展现物体的[立体](https://zh.wikipedia.org/wiki/%E7%AB%8B%E9%AB%94 "立体")感                                                                                                                                                                                                                                                                                                                             |
| 版画  | 常见的版画有[蚀刻版画](https://zh.wikipedia.org/wiki/%E8%9A%80%E5%88%BB%E7%89%88%E7%94%BB "蚀刻版画")、[油印木刻](https://zh.wikipedia.org/w/index.php?title=%E6%B2%B9%E5%8D%B0%E6%9C%A8%E5%88%BB&action=edit&redlink=1 "油印木刻（页面不存在）")、[水印木刻](https://zh.wikipedia.org/w/index.php?title=%E6%B0%B4%E5%8D%B0%E6%9C%A8%E5%88%BB&action=edit&redlink=1 "水印木刻（页面不存在）")、[黑白版画](https://zh.wikipedia.org/w/index.php?title=%E9%BB%91%E7%99%BD%E7%89%88%E7%94%BB&action=edit&redlink=1 "黑白版画（页面不存在）")、[套色版画](https://zh.wikipedia.org/w/index.php?title=%E5%A5%97%E8%89%B2%E7%89%88%E7%94%BB&action=edit&redlink=1 "套色版画（页面不存在）")等                                                                                                                                                                  |
|     | **蚀刻版画**：属于凹版印刷的一种，是用蚀刻针将图案刻画在一张有保护层（一般是蜡层）的金属板上，然后用酸浸泡金属板。划刻后暴露出来的金属被酸腐蚀，而其余部分仍有保护层覆盖。金属板在酸中浸泡的时间越长，刻痕的凹陷就越深。清洗干净刻板后，为其涂上油墨并再次清洗，只留下刻线内的墨汁。此时将湿纸和一层保护布将金属板包裹，通过蚀刻机的挤压，让纸与刻痕里的墨充分接触之后，便可制成一张版画作品。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|     | **石板版画**：用一种油脂类的介质——通常是特殊的石刻蜡笔或油腻的墨——在石版上绘画。石板经由化学溶液处理，所以只有图案区域吸附油墨，而空白区域则只会吸附水分。用滚筒将油墨涂在石版上，确保油墨只黏附在图像上。最后，将石版放在平版印刷机上，用潮湿的纸和纸板覆盖其上，用压力棒均匀施力，将石板上的图案转印出来。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|     | **丝网版画**：将图案刻在一张塑料薄膜上，制成模板后装框。框上带有一层细网，在装裱时覆盖在模板上，形成一层“屏幕”。在细网和模板间放一张纸，从上方用橡胶刮刀将墨推进模板里去。除了模板，摄影图像也可以用光敏明胶通过丝网技术印刷。丝网印刷对以安迪·沃荷（Andy Warhol）为代表的波普艺术家们的创作有着至关重要的影响。                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|     | **[木刻版画](https://zh.wikipedia.org/wiki/%E6%9C%A8%E5%88%BB%E7%89%88%E7%94%BB)：**先将草图画在一块木板上，按照草图对木板进行雕刻。在木板凸起的部分涂上墨，将一张纸放于其上进行挤压，这样木板凸起部分的图案就会反向印在纸上。木刻法是最古老的版画印刷方法，一部分浮世绘艺术正是木刻版画杰作。木刻版画令恩斯特·路德维格·基尔希纳（Ernst Ludwig Kirchner）等德国表现主义艺术家尤感兴趣，时至今日仍然为许多艺术家所使用，包括唐纳德·贾德（Donald Judd），达米恩·赫斯特（Damien Hirst）以及海伦·佛兰肯瑟勒（Helen Frankenthaler）。                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| 油画  | 传统油画以[亚麻籽油](https://zh.wikipedia.org/wiki/%E4%BA%9E%E9%BA%BB%E7%B1%BD%E6%B2%B9 "亚麻籽油")调和[颜料](https://zh.wikipedia.org/wiki/%E9%A2%9C%E6%96%99 "颜料")称为[油彩](https://zh.wikipedia.org/wiki/%E6%B2%B9%E5%BD%A9 "油彩")绘制。在经过处理的布或板上作画，因为油画颜料干后不变色，多种颜色调和不会变得肮脏，画家可以画出丰富、逼真的色彩。油画颜料不透明，覆盖力强，所以绘画时可以由深到浅，逐层覆盖，使绘画产生立体感。油画适合创作大型、史诗般的巨作。成为[西方绘画史](https://zh.wikipedia.org/w/index.php?title=%E8%A5%BF%E6%96%B9%E7%BB%98%E7%94%BB%E5%8F%B2&action=edit&redlink=1 "西方绘画史（页面不存在）")中的主体绘画方式，现在存世的西方绘画作品主要是油画作品。绝大部分[壁画](https://zh.wikipedia.org/wiki/%E5%A3%81%E7%94%BB "壁画")作品也是用油画颜料和创作方式制作的。19世纪后期，由于科技发展，许多新材料应用于油画领域，如[丙烯颜料](https://zh.wikipedia.org/wiki/%E4%B8%99%E7%83%AF%E9%A2%9C%E6%96%99 "丙烯颜料")或[油漆](https://zh.wikipedia.org/wiki/%E6%B2%B9%E6%BC%86 "油漆")而不局限于狭义的油彩等。 |

### 人物：
#### 丢勒
（德語：Albrecht Dürer；1471年5月21日—1528年4月6日），[德国文艺复兴](https://zh.wikipedia.org/wiki/%E5%BE%B7%E5%9B%BD%E6%96%87%E8%89%BA%E5%A4%8D%E5%85%B4 "德国文艺复兴")时期画家、版画家。
他生于[纽伦堡](https://zh.wikipedia.org/wiki/%E7%B4%90%E5%80%AB%E5%A0%A1 "纽伦堡")的金匠家庭，其父老阿尔布莱希特·丟勒原为[匈牙利](https://zh.wikipedia.org/wiki/%E5%8C%88%E7%89%99%E5%88%A9 "匈牙利")宫廷金匠，后移居纽伦堡。童年时代，丢勒随其父学习金工手艺，15岁后开始了其游学生活，随[瓦格莫特](https://zh.wikipedia.org/w/index.php?title=%E7%93%A6%E6%A0%BC%E8%8E%AB%E7%89%B9&action=edit&redlink=1 "瓦格莫特（页面不存在）")学习绘画和木刻，先后游历于[阿尔萨斯](https://zh.wikipedia.org/wiki/%E9%98%BF%E5%B0%94%E8%90%A8%E6%96%AF "阿尔萨斯")、[巴泽尔](https://zh.wikipedia.org/wiki/%E5%B7%B4%E6%BE%A4%E7%88%BE "巴泽尔")及[斯特拉斯堡](https://zh.wikipedia.org/wiki/%E6%96%AF%E7%89%B9%E6%8B%89%E6%96%AF%E5%A0%A1 "斯特拉斯堡")。随他最重要的游学经历为两次[意大利](https://zh.wikipedia.org/wiki/%E6%84%8F%E5%A4%A7%E5%88%A9 "意大利")的旅行，其间丢勒结识了画家[乔瓦尼·贝利尼](https://zh.wikipedia.org/wiki/%E4%B9%94%E7%93%A6%E5%B0%BC%C2%B7%E8%B4%9D%E5%88%A9%E5%B0%BC "乔瓦尼·贝利尼")和[拉斐尔](https://zh.wikipedia.org/wiki/%E6%8B%89%E6%96%90%E7%88%BE "拉斐尔")，同时研究了[达芬奇](https://zh.wikipedia.org/wiki/%E9%81%94%E6%96%87%E8%A5%BF "达芬奇")的作品和艺术理论，接触并学习了[文艺复兴](https://zh.wikipedia.org/wiki/%E6%96%87%E8%89%BA%E5%A4%8D%E5%85%B4 "文艺复兴")的思想及风格。

丢勒一生创作了大量木刻画、铜版画、油画和人物素描。其代表作有油画《[四使徒](https://zh.wikipedia.org/wiki/%E5%9B%9B%E4%BD%BF%E5%BE%92 "四使徒")》、《[亚当和夏娃](https://zh.wikipedia.org/wiki/%E4%BA%9A%E5%BD%93%E5%92%8C%E5%A4%8F%E5%A8%83_\(%E4%B8%A2%E5%8B%92\) "亚当和夏娃 (丢勒)")》、木版画《启示录》、铜版画《苦闷》、《骑士、死神、魔鬼》等。著有《人体比例研究》四卷，对透视学和人体解剖学颇有研究。

丢勒早在自己十三岁时（1484）就给自己画了一幅自画像，比达芬奇创作的那幅有名的自画像（ca. 1510-1515）还要早二十多年。在其一生之中，共创作了近十幅自画像，包括速写、素描、版画和油画等创作手法，其创作的自画像大多具有严整细致的特征，艺术表现力与后来的[伦勃朗](https://zh.wikipedia.org/wiki/%E4%BC%A6%E5%8B%83%E6%9C%97 "伦勃朗")遥相呼应。因此，丢勒被誉为[“自画像之父”](https://zh.wikipedia.org/zh-cn/%E9%98%BF%E5%B0%94%E5%B8%83%E9%9B%B7%E5%B8%8C%E7%89%B9%C2%B7%E4%B8%A2%E5%8B%92#cite_note-%E6%96%B9%E5%BB%BA%E8%8F%AF2012-6)。

他在1510年代前半创作出多个显现出精深技术的[雕版](https://zh.wikipedia.org/wiki/%E9%9B%95%E7%89%88 "雕版")画作，高度运用源自意大利的技巧和理论，甚至将[新柏拉图主义](https://zh.wikipedia.org/wiki/%E6%96%B0%E6%9F%8F%E6%8B%89%E5%9C%96%E4%B8%BB%E7%BE%A9 "新柏拉图主义")的思想融入创作内容中[3](https://zh.wikipedia.org/zh-cn/%E9%98%BF%E5%B0%94%E5%B8%83%E9%9B%B7%E5%B8%8C%E7%89%B9%C2%B7%E4%B8%A2%E5%8B%92#cite_note-:0-3)。他在晚年更加专注于艺术理论专著的写作，并在画作中显示出对于当时[宗教改革](https://zh.wikipedia.org/wiki/%E5%AE%97%E6%95%99%E6%94%B9%E9%9D%A9 "宗教改革")有关争议的关注[3](https://zh.wikipedia.org/zh-cn/%E9%98%BF%E5%B0%94%E5%B8%83%E9%9B%B7%E5%B8%8C%E7%89%B9%C2%B7%E4%B8%A2%E5%8B%92#cite_note-:0-3)。

#### 伦勃朗
宽裕的资产阶级家庭条件让他在家乡度过了无忧无虑的童年生活。他的母亲是[天主教徒](https://zh.wikipedia.org/wiki/%E5%A4%A9%E4%B8%BB%E6%95%99%E5%BE%92 "天主教徒")，父亲信奉[荷兰规正会](https://zh.wikipedia.org/wiki/%E8%8D%B7%E5%85%B0%E5%BD%92%E6%AD%A3%E4%BC%9A "荷兰归正会")，因此宗教成为了伦勃朗作品的核心主题之一，他所生活时期的浓厚宗教氛围也使他的信仰问题备受学界关注
伦勃朗的肖像画风格人物安排具有[戏剧](https://zh.wikipedia.org/wiki/%E6%88%8F%E5%89%A7 "戏剧")性，深深打动人心，他以[神话](https://zh.wikipedia.org/wiki/%E7%A5%9E%E8%AF%9D "神话")和[宗教](https://zh.wikipedia.org/wiki/%E5%AE%97%E6%95%99 "宗教")故事为题材的作品供不应求

从1640年代开始，他经常到乡村漫步和作画，创作了许多反映大自然的[素描](https://zh.wikipedia.org/wiki/%E7%B4%A0%E6%8F%8F "素描")和[版画](https://zh.wikipedia.org/wiki/%E7%89%88%E7%94%BB "版画")，风格质朴。1661年是他作画最多的一年，1663年以后就作画较少，结交了许多中下阶层的市民，眼界更为开阔，技巧更为成熟，创造力达到顶峰。

1642年伦勃朗创作《[夜巡](https://zh.wikipedia.org/wiki/%E5%A4%9C%E5%B7%A1 "夜巡")》，也是他生涯的转折点之一。《[夜巡](https://zh.wikipedia.org/wiki/%E5%A4%9C%E5%B7%A1 "夜巡")》是阿姆斯特丹射击协会的一群人合资请伦勃朗绘制的。伦勃朗在这些志愿民兵的群像构图上，未依照当时军人需依身份及军衔排列的不成文规定，因此造成民兵不满，要求重画，但伦勃朗没有答应，因此告上法庭，伦勃朗因此受到许多的攻击及疏远生有4个孩子，只有最小的一个存活，但他妻子在生孩子后不久去世。

他和女仆[亨德里克耶·斯托费尔斯](https://zh.wikipedia.org/w/index.php?title=%E4%BA%A8%E5%BE%B7%E9%87%8C%E5%85%8B%E8%80%B6%C2%B7%E6%96%AF%E6%89%98%E8%B4%B9%E5%B0%94%E6%96%AF&action=edit&redlink=1 "亨德里克耶·斯托费尔斯（页面不存在）")住在一起，斯托费尔斯为他生了一个女儿，为此受到教会的谴责为“罪恶的生活”。由于他为了画画经常采购大量的衣物和绘画工具，从不计较财产，所以很快就到了[破产](https://zh.wikipedia.org/wiki/%E7%A0%B4%E4%BA%A7 "破产")的边缘。

晚年的伦勃朗获得一个翻身的机会。阿姆斯特丹刚刚建成的市政厅，需要一幅表现古代荷兰英雄[克劳迪乌斯·西维利斯](https://zh.wikipedia.org/w/index.php?title=%E7%9B%96%E4%B9%8C%E6%96%AF%C2%B7%E5%B0%A4%E5%88%A9%E4%B9%8C%E6%96%AF%C2%B7%E8%A5%BF%E7%BB%B4%E5%88%A9%E6%96%AF&action=edit&redlink=1 "盖乌斯·尤利乌斯·西维利斯（页面不存在）")（Claudius Civilis）反抗罗马暴政的巨幅画作。 然而他的画却让政府官员对他彻底失望了，英雄西维利斯是独眼残疾人这没错， 但他没有像其他画家只画他健全的那一侧，最后为了生计，他将这幅画砍得七零八落。

1669年他在贫病中去世，身边只有女儿陪伴，死后葬在西教堂一个无名墓地中。

伦勃朗一生留下600多幅油画，300多幅蚀版画和200多幅素描，几乎画了100多幅自画像，而且几乎他所有的家人都在他的画中出现过。

#### 戈雅
##### 弗朗西斯科·戈雅
是西班牙[浪漫主义](https://zh.wikipedia.org/wiki/%E6%B5%AA%E6%BC%AB%E4%B8%BB%E7%BE%A9 "浪漫主义")画家与[版画](https://zh.wikipedia.org/wiki/%E7%89%88%E7%95%AB "版画")家。他被认为是18世纪末至19世纪初最重要的西班牙艺术家。他的画作、素描与版画反映了当时的历史动荡，并对19至20世纪的重要画家产生了深远影响。戈雅常被誉为“最后一位[古典大师](https://zh.wikipedia.org/wiki/%E5%8F%A4%E7%BE%8E%E6%9C%AF%E5%A4%A7%E5%B8%88 "古美术大师")与第一位现代大师”。
戈雅1746年出生于[阿拉贡](https://zh.wikipedia.org/wiki/%E9%98%BF%E6%8B%89%E8%B4%A1 "阿拉贡")的[丰德托多斯](https://zh.wikipedia.org/wiki/%E4%B8%B0%E5%BE%B7%E6%89%98%E5%A4%9A%E6%96%AF "丰德托多斯")一个中产阶级家庭。他早年在萨拉戈萨学画，后迁至马德里发展。1786年，戈雅成为[西班牙王室](https://zh.wikipedia.org/wiki/%E8%A5%BF%E7%8F%AD%E7%89%99%E5%90%9B%E4%B8%BB "西班牙君主")的宫廷画家，其早期职业生涯以绘制西班牙贵族与皇室肖像，以及为皇宫设计的[洛可可](https://zh.wikipedia.org/wiki/%E6%B4%9B%E5%8F%AF%E5%8F%AF "洛可可")风格[挂毯草图](https://zh.wikipedia.org/w/index.php?title=%E6%8E%9B%E6%AF%AF%E8%8D%89%E5%9C%96&action=edit&redlink=1 "挂毯草图（页面不存在）")为代表。1793年，一场原因不明的重病使他[失聪](https://zh.wikipedia.org/wiki/%E5%A4%B1%E8%81%B0 "失聪")，这成为其人生的转捩点，此后其作品风格愈发阴暗与悲观。他后期的[架上绘画](https://zh.wikipedia.org/w/index.php?title=%E6%9E%B6%E4%B8%8A%E7%B9%AA%E7%95%AB&action=edit&redlink=1 "架上绘画（页面不存在）")与[壁画](https://zh.wikipedia.org/wiki/%E5%A3%81%E7%95%AB "壁画")、版画与素描，似乎反映了其在个人、社会与政治层面上的黯淡前景，与他早年追求社会地位的风格形成对比。

他曾担任[圣费尔南多皇家美术学院](https://zh.wikipedia.org/wiki/%E5%9C%A3%E8%B4%B9%E5%B0%94%E5%8D%97%E5%A4%9A%E7%9A%87%E5%AE%B6%E7%BE%8E%E6%9C%AF%E5%AD%A6%E9%99%A2 "圣费尔南多皇家美术学院")院长，并于1799年晋升为“首席宫廷画家”（Primer Pintor de Cámara）。[半岛战争](https://zh.wikipedia.org/wiki/%E5%8D%8A%E5%B2%9B%E6%88%98%E4%BA%89 "半岛战争")期间，戈雅留在马德里，这段经历似乎对他产生了深刻影响。其感受可从《[战争的灾难](https://zh.wikipedia.org/wiki/%E6%88%B0%E7%88%AD%E7%9A%84%E7%81%BD%E9%9B%A3 "战争的灾难")》系列版画以及《[1808年5月2日](https://zh.wikipedia.org/w/index.php?title=1808%E5%B9%B45%E6%9C%882%E6%97%A5&action=edit&redlink=1 "1808年5月2日（页面不存在）")》与《[1808年5月3日](https://zh.wikipedia.org/wiki/1808%E5%B9%B45%E6%9C%883%E6%97%A5 "1808年5月3日")》等画作中窥见。他的晚期创作以1819至1823年间的《[黑色绘画](https://zh.wikipedia.org/wiki/%E9%BB%91%E8%89%B2%E7%B9%AA%E7%95%AB "黑色绘画")》达到顶峰。这些画作直接绘于其居所“[聋人之家](https://zh.wikipedia.org/w/index.php?title=%E8%81%BE%E4%BA%BA%E4%B9%8B%E5%AE%B6&action=edit&redlink=1 "聋人之家（页面不存在）")”的墙上，当时他对西班牙的政治与社会发展感到幻灭，过着近乎与世隔绝的生活。1824年，戈雅最终离开西班牙，迁居法国[波尔多](https://zh.wikipedia.org/wiki/%E6%B3%A2%E7%88%BE%E5%A4%9A "波尔多")，并于1828年逝世，享寿82岁。
